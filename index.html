Frequently Asked Questions

What is a testnet faucet? ▼
A testnet faucet distributes free test tokens that have no real-world value. These tokens let developers and users interact with the Prime Chain testnet to test smart contracts, DApps, and integrations without risking real funds.
How much can I claim? ▼
Each PRIM faucet request dispenses 1,000 PRIM to your wallet. For mock ERC-20 tokens (USDC, USDT, DAI), the contract's faucet() function mints 10,000 tokens per call. This should be enough for most testing scenarios.
How often can I claim? ▼
PRIM tokens are rate-limited to 1 request per address per hour. Mock ERC-20 tokens (USDC, USDT, DAI) can be claimed at any time since the faucet() function is public and does not have built-in cooldowns.
What are mock tokens? ▼
Mock tokens (MockUSDC, MockUSDT, MockDAI) are ERC-20 test tokens deployed on Prime Chain that simulate popular stablecoins. They allow you to test DEX swaps, lending protocols, and other DeFi integrations. Each contract has a public faucet() function that anyone can call to mint tokens.
How do I add Prime Chain to MetaMask? ▼
Click the "Add Prime Chain to MetaMask" button in the Network Details panel above, or manually add it in MetaMask with these settings:

• Network Name: Prime Chain Testnet
• RPC URL: http://46.225.30.187:8545
• Chain ID: 7919
• Currency Symbol: PRIM
• Block Explorer: http://46.225.30.187/
Why hasn't my transaction confirmed? ▼
Transactions usually confirm within a few seconds on Prime Chain. If your transaction is pending:

• Check the block explorer using the transaction hash.
• Ensure you are connected to the correct network (Chain ID 7919).
• The faucet wallet may temporarily be out of funds — try again later.
• For MetaMask claims, make sure you have some PRIM for gas (claim PRIM first!).
