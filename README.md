# Prime Faucet

Testnet faucet for Prime Chain — distributes testnet PRIM tokens to developers and users.

**Live:** [http://46.225.30.187:4005](http://46.225.30.187:4005)

## Features

- Request testnet PRIM tokens
- Wallet address input with validation
- Rate limiting display
- Transaction confirmation with explorer link
- Clean, responsive UI

## Tech Stack

- Single HTML file with inline CSS/JS
- ethers.js v6 for transaction signing

## Deployment

```bash
scp index.html user@server:/var/www/faucet/
```
